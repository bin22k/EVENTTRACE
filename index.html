⚠️ Đã nhận diện file nhị phân Windows Event Log (.evtx) —

Do .evtx là định dạng nhị phân nén (Binary XML), trình duyệt đã quét nhanh các chuỗi IP/tài khoản đọc được trong bộ đệm bên dưới. Để trích xuất đầy đủ 100% mã sự kiện (4624 / 4625 / 4740) và timestamp chính xác, hãy lưu dưới dạng .xml trong Event Viewer hoặc chạy lệnh PowerShell sau trên máy Windows:

Get-WinEvent -Path ".\Security.evtx" | Select-Object TimeCreated,Id,MachineName,Message | Export-Csv ".\security.csv" -NoTypeInformation -Encoding UTF8

Hỗ trợ: Windows Event Viewer XML (<Event>...</Event>), Windows Security CSV (4624/4625/4740), quét nhanh file nhị phân .evtx, log key=value và Linux sshd/auth.log.

Chưa có dữ liệu. Nạp log mẫu hoặc chọn file (.xml / .evtx / .csv / .log) của bạn ở trên để bắt đầu điều tra.
